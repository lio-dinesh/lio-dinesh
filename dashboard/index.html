About the refresh speed

The dashboard checks the repository data every 30 seconds. GitHub Actions collects the latest available platform data every 5 minutes. A typing test appears after Monkeytype records the completed test; a submission appears after LeetCode or CodeChef publishes it. This is frequent polling, not live capture of keystrokes or an instant provider webhook.
